These are the one-off scripts that built the launch dataset, kept for provenance. They read cloned source repos and scraped pages under /workspace/research on the build box, so they won't run anywhere else as-is. Run order: build_items.py, then fetch_media.py, then render_posters.mjs (screenshots of the published CommandCode HTML pages, used as posters). To add new entries, use `npm run add-item` instead.
